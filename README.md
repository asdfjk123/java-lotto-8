# java-lotto-precourse

---

## 기능
### 입력

- 구입 금액 입력
  - 숫자가 아닐 때 exception
  - 양의 정수가 아닐 때 exception
  - 나누어 떨어지지 않을 때 exception
- 당첨 번호 입력
  - 쉼표, 숫자 제외 다른 문자가 들어갔을 때 exception
  - 숫자가 6개가 아닐 때 exception
  - 숫자 범위가 1~45 가 아닐 때 exception
  - 이미 사용된 숫자가 입력되었을 때 exception
- 보너스 번호 입력
  - 숫자가 아닐 때 exception
  - 숫자 범위가 1~45 가 아닐 때 exception
  - 이미 사용된 숫자가 입력되었을 때 exception
- exception 시 다시 입력 받기
### 계산

- 구매한 N개 로또만큼, 각 로또 당 1~45 범위의 서로 다른 숫자 6개 뽑기
- 각 로또 당, 당첨 번호 6개와 숫자 비교
  - 숫자 일치 개수 계산
    - 일치 개수가 5개인 경우, 나머지 1개 숫자의 보너스 볼 일치 여부 계산
- 수익률 계산 (수익률 = (당첨 금액 / 구매 금액) * 100)


### 출력

- "구입금액을 입력해 주세요." 문장 출력
- "N개를 구매했습니다." 문장 출력
- N개의 로또에 대한 자동 추첨 번호 출력
- "당첨 번호를 입력해 주세요." 문장 출력
- "보너스 번호를 입력해 주세요." 문장 출력
- 당첨 통계 출력
